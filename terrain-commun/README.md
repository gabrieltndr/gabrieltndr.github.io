# Terrain Commun — site vitrine (Ligue 14)

Site statique en un seul fichier (`index.html`, CSS et JS intégrés), sans dépendance ni étape de build.

- `index.html` : le site
- `assets/favicon.svg`, `assets/og-image.jpg` : icône et image de partage
- `sitemap.xml` : pour Google Search Console

## À personnaliser
- **Formulaire** : dans `index.html`, renseigner `FORM_ENDPOINT` (adresse Formspree) pour recevoir les demandes par email.
- **Coordonnées** : remplacer `contact@votre-domaine.fr` et `02 00 00 00 00`.
- **Nom** : remplacer « Terrain Commun » une fois le nom définitif choisi.
- **Photos** : photos Unsplash (licence Unsplash), à remplacer par vos vraies photos d'événements dès la saison 1.
